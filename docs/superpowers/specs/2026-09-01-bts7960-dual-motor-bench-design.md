# BTS7960 双电机架空闭环设计

## 1. 项目定位

OpenRobot-One 保留已验证的 ROS 2 双轮差速仿真，同时把当前真机目标冻结为“双电机架空闭环验证台”：

```text
/cmd_vel
  -> 参数化差速运动学
  -> left_target_rpm / right_target_rpm
  -> ROS 2 串口驱动
  -> STM32F407 双通道安全状态机与 PID
  -> 两块 IBT-2/BTS7960
  -> 两台 JGA25-370
  -> 两路 AB 编码器
  -> wheel feedback
  -> /bench/odom_estimate + diagnostics
```

仿真和真机台架共享 `/cmd_vel`、差速运动学参数、左右轮命令/反馈语义和协议测试向量。仿真验证系统级 Topic、TF、LaserScan 和 SLAM；真机台架验证真实双执行通道、编码器、PID、UART 和故障停车。

没有底盘、轮子和地面运动证据时，`/bench/odom_estimate` 只代表架空编码器估算；不发布真机 `odom -> base_footprint` TF；不宣称真实里程计精度、落地运动、真机 SLAM 或 Nav2。

## 2. 已购硬件与当前缺口

按用户最新采购与接线信息，当前范围包括 STM32F407ZGT6、ST-Link V2、CH340、两块 IBT-2/BTS7960、两台 12 V/620 RPM 带 AB 编码器的 JGA25-370、12 V/5 A 适配器、正负极一进二出端子、20 AWG 动力线和 2.54 mm 控制线。

这些硬件在功能上足以构建双电机架空速度闭环，但以下项目仍是通电前置：万用表、保险丝、直流额定总开关/急停、限流方案、可靠固定与绝缘，以及两块模块逻辑阈值、编码器电平、启动/堵转电流实测。

## 3. 商品资料边界

三张 IBT-2 商品截图只能记录为卖家资料：型号标称 `IBT-2`，动力电压分别出现 `5.5–27 V` 和 `6–27 V`，输入电平标称 `3.3–5 V`，VCC 标称 5 V，PWM 标称最高 25 kHz，控制端为 `RPWM/LPWM/R_EN/L_EN/R_IS/L_IS/VCC/GND`，动力端为 `B+/B-/M+/M-`。

`43 A` 不作为连续能力或小电机保护依据。截图同时出现74HC244和“74HC224”，卖家芯片文字存在冲突；即使实物为74HC244，“隔离”也不等于电气隔离，系统仍需共地。STM32 3.3 V 高电平是否满足实际模块规格必须实测；未确认前保持 `UNKNOWN`。商品图对 RPWM/LPWM 正反转定义互相冲突，方向只能通过架空低能量脉冲冻结。

## 4. 无冲突候选引脚

| 功能 | STM32 候选 | 初始状态 |
| --- | --- | --- |
| 左 `RPWM/LPWM` | `PB6/PB7 / TIM4_CH1/CH2` | PWM=0 |
| 右 `RPWM/LPWM` | `PB8/PB9 / TIM4_CH3/CH4` | PWM=0 |
| 左 `R_EN/L_EN` | `PC0/PC1` | GPIO低 |
| 右 `R_EN/L_EN` | `PC2/PC3` | GPIO低 |
| 左编码器 A/B | `PA0/PA1 / TIM2_CH1/CH2` | 输入 |
| 右编码器 A/B | `PA6/PA7 / TIM3_CH1/CH2` | 输入 |
| CH340 USART1 | `PA9/PA10` | 保留现有 H2 基线 |
| SWD | `PA13/PA14` | 保留 |
| LED | `PC13` | 保留 |

四个 EN 各使用外部约 `10 kΩ` 下拉至 GND。禁止把 EN 永久接 5 V。PWM 引脚先作为低电平 GPIO 初始化，比较值为 0 后再切换定时器复用。

用户原接线中的 `PA8/PA9/PA10/PA11` 四 PWM 方案作废：`PA9/PA10` 已用于 USART1，`PA11` 还有板载 USB 负载。CH340 继续使用 `TXD -> PA10`、`RXD <- PA9`、GND共地。

## 5. 动力与信号接线边界

```text
12 V 正极 -> 总保险/开关 -> 正极分线端子
                           ├-> 左分支保险 -> 左 BTS B+
                           └-> 右分支保险 -> 右 BTS B+

12 V 负极 -> 负极分线端子
             ├-> 左 BTS B-
             └-> 右 BTS B-

左 BTS M+/M- -> 左电机动力线
右 BTS M+/M- -> 右电机动力线
```

两块 BTS、STM32、编码器、CH340 与 12 V 负极建立公共参考地。12 V 不进入 STM32 5 V/3.3 V 或编码器接口。编码器 VCC 和 A/B 电平必须先测量。ST-Link 的 3.3 V 默认只作为目标参考电压，不得与其他供电互相反灌。

## 6. H0–H5 验收门

### H0：装备和固定

双电机分别可靠固定并架空；限流、保险丝、急停/总开关、万用表和合格线材齐全；动力端无杜邦线、裸铜或松动。

### H1：断电电气核查

逐块确认模块端子方向、无明显短路、公共地、极性、5 V 逻辑供电和 EN 下拉；测量 3.3 V 控制高电平兼容性与编码器供电/A/B高电平。不满足时增加正式电平转换。

### H2：无动力固件安全

电机动力断开；上电、复位、Fault、串口错误和异常处理均令四个 EN 为低、四路 PWM 为零；现有 H2 UART 回归继续通过；当前半包清理不算电机看门狗。

### H3：逐通道受控脉冲

先左后右，每次仅授权一个通道执行 `5%/100 ms` 单方向脉冲；每个后续台阶重新授权；到期、复位、串口断开和 PC 退出均禁止输出；实测冻结方向与编码器符号。

### H4：双电机闭环

两个编码器各手转一圈 3 次，计数离散度不高于 1%；分别完成单通道开环后再进入双通道。在安全范围内选低/中/高三个目标点，每点无轮空载运行 10 s、重复 3 次；最后 5 s 稳态误差不高于 10%，峰峰值不高于目标绝对值的 15%。只有新运动命令刷新 500 ms 运动看门狗；连续 10 次超时试验中 PWM和EN关闭延迟均不高于 550 ms。

### H5：ROS 2 架空闭环

`/cmd_vel` 使用版本化轮径、轮距和限幅参数转换为左右目标 RPM；零速、直行、原地旋转和混合运动四组参考向量验证离线公式、ROS输出和STM32目标一致。发布左右目标、实测RPM、编码器计数、状态、故障和 `/bench/odom_estimate`；不发布真机TF，不替代标准 `/odom`。保存至少1000个样本的P50/P95/最大延迟、丢失数和序号异常数。

任一安全项失败，停止后续非零测试并标记 `BLOCKED`。

## 7. 协议与软件边界

线协议至少包含 `SET_WHEEL_RPM(left,right,sequence)`、`STOP(sequence)`、只证明传输存活的 `HEARTBEAT(sequence)`、`WHEEL_STATE(...)` 和 `FAULT(...)`。CRC、字节序、饱和、序号回绕、超时、截断、粘包和噪声均需 PC/STM32 测试向量。运动命令新鲜度与传输心跳分离。

## 8. 专业能力证据

当前已有证据可写：ROS 2/Gazebo/SLAM 系统集成，STM32 H2 下载和 UART 压力/异常恢复，H0–H5 分层设计和安全边界。

H4/H5 实测通过后才可写：完成双电机编码器测速、双通道速度 PID 和命令超时停车；完成 `/cmd_vel` 到 STM32 双执行通道、反馈和架空估算里程计闭环；建立仿真、协议与真机台架的统一参考向量和自动化验收。

不得写成落地真机底盘、真实里程计精度或真机自主导航。
