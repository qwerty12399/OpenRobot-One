## 2. 目标与现有驱动板的处理

当前方案使用两块 DRV8871 模块，每块独立驱动一台电机。用户报告模块商品标称为 3.6 A，但该数字不能代替持续电流、限流电阻、散热条件和电机启动/堵转电流实测。旧 TB6612FNG 仅保留为历史备件，不进入当前 H3 接线方案。

禁止仅凭芯片宣传峰值电流判定安全。若实测电流接近驱动器连续能力，应更换驱动器而不是降低保险丝保护或忽略温升。

## 3. 首次电机上电前必须准备

| 物品 | 最低要求 | 用途 |
| --- | --- | --- |
| 带电压/电流显示及可调限流的直流电源 | 0–15 V；双电机目标额定输出至少 12 V / 10 A | 不使用万用表时，只按铭牌和电源面板读数进行先单电机、后双电机调试 |
| 保险丝与座 | 首次单电机 2 A；完整双电机回路按导线和电源能力另行冻结 | 接线错误和堵转保护；熔断后不直接加大规格 |
| 总电源开关 | 12 V / 5 A 或更高 | 紧急断电 |
| 电解电容 | 1000 µF / 25 V | 驱动板 VM 端抑制跌落 |
| 陶瓷电容 | 0.1 µF | 电源和电机端高频去耦 |
| 合格导线 | 电机回路建议 20–22 AWG | 避免杜邦线和面包板承载电机电流 |
| 热缩管/端子 | 可靠绝缘和固定 | 防止松脱短路 |

## 4. 必须实测后才能冻结的参数

- 编码器供电、电平、A/B 相序和每输出轴一圈计数。
- 左右电机正方向、编码器正方向和两侧符号。
- 驱动轮有效滚动直径、轮宽和左右轮接地点中心距。
- 单电机空载、启动、负载和堵转电流；驱动板温升。
- 整车质量、重心、电池续航和最大安全速度。
- STM32 的最终 PWM、方向、刹车/使能和编码器定时器引脚。

这些参数在 `openrobot_bringup/config/robot.yaml` 中保持显式无效值或仿真值，并标明来源。未标定时真机软件必须禁止非零运动。

## 5. 上位机升级路线

1. 第一阶段使用开发 PC，降低成本并便于调试。
2. 需要脱机运行时升级树莓派 5，先验证 CPU 视觉性能。
3. 只有高帧率或更大模型确有需求时再升级 Jetson。

不在 MVP 阶段同时采购多套计算平台。
