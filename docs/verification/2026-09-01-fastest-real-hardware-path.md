# 现阶段最快真机实测路径

## 结论

当前最快且已经完成的真机结果是 STM32 + ST-Link + CH340 板级通信闭环。没有万用表、限流、保险丝和直流断电开关时，不执行 DRV8871 或电机通电。

## 已完成（无需采购）

1. STM32F407 下载、verify、复位和寄存器检查。
2. USART1 115200 8N1 双向通信。
3. 10000/10000 次 PING/PONG。
4. 20/20 次复位与串口重连。
5. 未知帧、超长帧、500 ms 半包超时和错误波特率恢复。
6. ELF Flash `R E`、RAM `RW`，无 RWX 段。

## 最快解锁电机实转的采购顺序

必须一次购齐，不能只买其中一件：

1. UT33D+ 或同级数字万用表：直流电压、电阻、通断档。
2. 32 VDC ATO/ATC 串联保险丝座，14 AWG 引线；2 A、3 A、5 A 保险片。
3. 不低于 24 VDC/10 A 的锁定开关或急停开关，必须有 DC 额定标识。
4. 12 V/21 W 白炽汽车灯泡和灯座，作为首次单电机上电的串联粗限流。
5. 1000 µF/25 V 电解电容、0.1 µF 陶瓷电容、20–22 AWG 导线、端子和热缩管。

不建议为了“更快”先买更大电源；上述物料未齐前，电机保持断开。

## 到货后的最快操作

1. 先创建并单独验收专用脉冲固件：候选使用 PB6/TIM4_CH1 -> IN1、PB7/TIM4_CH2 -> IN2；上电默认双低，只接受一次 5%/100 ms 脉冲。当前 H2 固件不具备该功能，不能直接用于电机实验。
2. 只接一块 DRV8871 和一台电机，另一套完全断开，轮子架空。
3. 断电测量 VM/GND 无短路，确认 POWER 与排针 VM/GND 对应关系和电解电容极性。
4. 连接 `12 V 正极 -> 2 A 保险丝 -> DC 开关 -> 12 V/21 W 灯泡 -> VM`，所有 GND 共地。
5. STM32 先上电，用万用表确认 PB6/PB7 均为低电平，再闭合 VM 开关。
6. 首次只发单方向 5% 占空比、100 ms 脉冲，随后立即回到 IN1=0、IN2=0。
7. 灯泡持续高亮、保险丝熔断、模块或导线发热、异味、异常噪声或不受控时立即断电并停止；不得提高保险丝规格或占空比继续尝试。

## 明确不做

- 不做双电机、落地运行、堵转、反复换向、编码器、PID 或真机里程计。
- 不把板级通信通过写成电机链路通过。
