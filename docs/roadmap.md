# 开发路线

项目按一条统一链路推进：仿真验证系统级接口，真机台架验证真实双执行通道，ROS 2 在 H5 汇合两类证据。

## 阶段 0：已完成基线

- [x] ROS 2 Humble、Docker、CI 和包结构；
- [x] Gazebo 双轮差速、LaserScan、SLAM Toolbox 和 TF；
- [x] STM32F407ZGT6 构建、下载、verify；
- [x] USART1 H2 通信、压力、异常恢复和复位重连。

## 阶段 1：H0/H1 安全与电气

1. 核对两块 IBT-2、两台电机、电源、端子和线材实物。
2. 补齐保险丝、急停/开关、限流和万用表条件。
3. 使用无冲突引脚表，安装四个 EN 外部下拉。
4. 逐块测量模块输入阈值和逐台测量编码器电平。

完成标准：接线表、照片和测量记录齐全；否则保持 `BLOCKED`。

## 阶段 2：H2 无动力固件安全

1. 配置 TIM4 四路 PWM、PC0-PC3 EN、TIM2/TIM3编码器候选。
2. 保证上电、复位、Fault和异常处理输出安全状态。
3. 保留 USART1 H2 基线并加入电机安全状态测试。
4. 建立正式协议测试向量和独立运动命令看门狗。

完成标准：不接动力时所有启动/故障路径均可证明 EN低、PWM零。

## 阶段 3：H3/H4 双电机架空闭环

1. 左右逐通道受控脉冲。
2. 两编码器手转标定和符号冻结。
3. 单通道开环与RPM计算。
4. 单通道 PID后再进入双通道PID。
5. 三目标点、重复性、振荡和500 ms看门狗验收。

## 阶段 4：H5 ROS 2 集成

1. 实现 `/cmd_vel` 到左右目标 RPM 的参数化差速运动学。
2. 实现 ROS 2串口驱动、重连、诊断和日志。
3. 发布 `/bench/*` 目标、反馈、状态和 `/bench/odom_estimate`。
4. 用四组参考向量验证仿真、离线公式、ROS和STM32一致性。
5. 保存延迟、丢失、序号和停车原始证据。

完成标准：双电机台架真实闭环和ROS数据链可复现；不发布真机TF。

## 远期扩展

底盘、轮子、电池、落地里程计、真机SLAM/Nav2、视觉和任务模块不属于当前完成标准。
