## 卖家标称

- IBT-2，双BTS7960 H桥；
- 动力约6–27V，输入3.3–5V，PWM最高25kHz；
- VCC=5V；接口为RPWM、LPWM、R_EN、L_EN、R_IS、L_IS、VCC、GND；
- 最大43A。

## 冲突与限制

- 截图同时写5.5–27V和6–27V。
- 两张图对RPWM/LPWM正反转语义互相颠倒。
- 43A不得解释为实物连续能力。
- 截图同时写74HC244和“74HC224”，卖家芯片文字存在冲突；两者均不能被解释为电气隔离证明，系统仍需共地。
- 5V供电74HC244是否保证识别STM32 3.3V高电平尚未实测。
- R_IS/L_IS比例和安全输入范围未知，首次不接。

方向、逻辑阈值、连续电流、温升和保护能力全部以逐块实物测试为准。
