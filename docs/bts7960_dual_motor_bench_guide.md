# BTS7960 双电机架空实验指南

本指南只描述进入实验前的顺序。当前H0/H1仍为 `BLOCKED`，不得据此直接通电。

## 安全接线基线

```text
12V+ -> 保险/急停 -> 正极分线 -> 左右分支保险 -> 两块BTS B+
12V- -> 负极分线 --------------------------> 两块BTS B-
两块BTS M+/M- ------------------------------> 两台电机动力线
```

四路PWM使用 `PC6/PC7/PB0/PB1`；四路EN使用 `PC0-PC3` 并各外接约10kΩ下拉；双编码器使用 `PA0/PA1` 和 `PE9/PE11`；CH340保留 `PA9/PA10`。PB6/PB7 连接板载 RTC 晶振，不得接右编码器。

## 推进顺序

1. 拍摄两块模块、两电机、电源和端子实物。
2. 断电测量端子、极性、短路、公共地和EN下拉。
3. 测量模块3.3V输入兼容性与两编码器电平。
4. 不接动力验证启动、复位和Fault时EN低/PWM零。
5. 左通道5%/100ms脉冲。
6. 右通道5%/100ms脉冲。
7. 左右编码器手转标定。
8. 单通道开环、单PID。
9. 双通道PID和500ms看门狗。
10. ROS 2 `/cmd_vel`、反馈、诊断与 `/bench/odom_estimate`。

每一步失败都停止后续非零测试。商品页接线图不能替代实物和测量。
