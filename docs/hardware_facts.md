# OpenRobot-One 真机硬件事实

本文只记录已经从实物照片、开发板资料或参考例程确认的内容。没有测量或没有资料支持的值必须保持 `UNKNOWN`，不能用同型号常见值替代。

## 已确认

### STM32 开发板

- 板卡：`LXBF407ZG-P1 V2.0`。
- MCU：`STM32F407ZGT6`，LQFP144。
- 板上引出 `5V`、`3V3`、`GND`，供电说明建议使用 5 V 或 USB；板上 3.3 V 稳压输出对外负载上限标注为 500 mA。
- 板载用户 LED：`PC13`，参考例程显示为低电平点亮。
- 板载调试接口：`SWDIO=PA13`、`SWCLK=PA14`；实际下载仍需按板上标识连接 SWDIO、SWCLK、GND 和参考电压。
- 参考例程使用 `USART1`：`PA9=TX`、`PA10=RX`，115200 波特率；接 CH340 时需要 TX/RX 交叉。

以上引脚来自板卡丝印、随板 `F407ZG.ioc` 和 HAL 参考例程。它们是开发板资源事实，不代表电机控制引脚已经分配。

### 电机

- 外壳标签：`JGA25-370`。
- 标签可读参数：`DC 12V 620RPM`。
- 数量：2 个。
- 确认是带后置编码器的型号，但照片无法确认编码器供电、输出电平、A/B 相顺序、PPR/CPR、减速比和堵转电流。

### 电机驱动

- 当前计划使用两块 `DRV8871` H 桥模块，每块对应一台电机。
- 用户报告商品标称为 `3.6 A DC Motor DRIVER`；该信息尚无仓库照片或订单页佐证，只能作为用户提供的型号信息。
- 旧 `TB6612FNG` 模块仍在历史照片中，但不再作为当前 H3 方案的驱动器。
- DRV8871 模块的具体端子、控制逻辑、ILIM/限流设定、去耦、电源走线和散热必须以实物正反面照片、丝印和对应资料核对，不能按网络通用模块照抄。

`硬件参数图片/drv8871/` 中的商品页与模块展示图可确认目标版型具有：

- 控制排针：`IN1`、`IN2`、`VM`、`GND`。
- 电机输出：正面标为 `MOTOR 1/2`，背面标为 `OUT1/OUT2`。
- 电源输入：独立 `POWER` 焊盘/端子，并在背面标出 `VM/GND`。
- 板载电解电容的展示图标称为 `47 µF / 50 V`。
- 展示图没有可见的故障输出端；ILIM 电阻的丝印/阻值无法从现有分辨率可靠读取。

用户确认这组图片对应实际使用的两块 DRV8871 模块版型，可据此冻结端子名称和模块拓扑。现有图片仍不能给出 ILIM 电阻的可靠阻值，也不能证明两块模块逐块的焊接、极性、损伤或一致性；没有万用表时仍不能验证 `POWER` 端与排针 `VM/GND` 的连通关系。

新增实物近照 `硬件参数图片/drv8871/DRV8871实物近照-芯片与限流电阻.jpg`：

- 芯片顶标可辨认 `8871` 与 `TI`，结合 PCB 丝印确认实物使用 DRV8871 芯片。
- 芯片与周边焊点在照片中未见明显桥连，但照片不能代替通断和短路测量。
- 右侧贴片电阻末位字符在照片中无法可靠区分 `C` 或 `E`，且仅凭位置不能证明其一定连接 ILIM。按 EIA-96 两种读法会产生数量级差异，因此在万用表测量或取得模块原理图前，不写入 RILIM 或电流阈值。
- 照片 SHA-256：`2044D28FDA252612001CACAD8F0021B8DA7A7A5285C5C590B1D990A6AC011DBF`。

TI 芯片级资料可确认但不能直接外推到模块板：DRV8871 芯片工作电压范围为 6.5–45 V，3.6 A 是峰值驱动能力；IN1/IN2 控制单个 H 桥，ILIM 外接电阻决定电流调节阈值。芯片具备欠压、过流和过温保护并会在故障移除后自动恢复，但这些内部保护不能替代外部保险丝、限流电源和紧急断电开关。

### USB-TTL

- 芯片/模块：`CH340G` USB-TTL。
- 模块有 `3.3V/5V` 电平选择；连接 STM32F407 的 UART 前应置于 3.3 V。按用户要求不使用万用表，首次连接只采用已完成 H2 验收的同一 CH340 模块、跳帽位置和接线方式，不据此外推其他模块。
- 真机串口暂定使用 115200 8N1；未确认前不要把 USB 5 V 直接接入 STM32 的 3.3 V 信号引脚。

## 仍为 UNKNOWN 的硬件事实

以下值在完成订单页核对或实测前不能写入 `robot.yaml`、固件或里程计公式：

- 电机编码器原始 PPR/CPR、倍频方式和减速比折算后的输出轴每圈计数。
- 编码器供电电压、A/B 输出高电平和是否需要电平转换。
- 两个电机的堵转电流、启动电流和持续电流。
- 两块 DRV8871 模块的版本、ILIM/限流设定、实际持续电流能力、散热和 VM 去耦配置。
- 电机电源的额定电压、持续电流和保险丝规格。
- 驱动轮有效直径与左右轮接地点中心距。
- STM32 上用于两块 DRV8871 控制输入、编码器和故障输入（若模块引出）的最终 GPIO/定时器分配。

## 第一阶段允许的候选资源

这些只是用于规划，使用前必须在 CubeMX、板卡原理图和实物上复核：

| 功能 | 候选资源 | 状态 |
| --- | --- | --- |
| 调试 | PA13/PA14 SWD | 已由板卡资料确认 |
| 调试 LED | PC13 | 已由参考例程确认 |
| CH340 串口 | USART1 PA9/PA10 | 已由参考例程确认 |
| 左右编码器 | TIM2/TIM3 或其他支持编码器模式的定时器 | 未确认 |
| 两路电机 PWM/控制 | 支持两块 DRV8871 独立控制的定时器/GPIO | 模块引脚未核验 |
| DRV8871 故障/限流 | 取决于模块是否引出对应端子 | 未确认 |

### 最快控制引脚候选（尚未写入固件）

开发板背面丝印确认 PB6、PB7、PB8、PB9 均已引出；当前 `OpenRobotFirmware.ioc` 未占用这些引脚。STM32F407ZG 官方复用表对应：

| 功能候选 | MCU 引脚 | 复用功能 | 状态 |
| --- | --- | --- | --- |
| 左 DRV8871 IN1 | PB6 | TIM4_CH1 / AF2 | 候选，未接线 |
| 左 DRV8871 IN2 | PB7 | TIM4_CH2 / AF2 | 候选，未接线 |
| 右 DRV8871 IN1 | PB8 | TIM4_CH3 / AF2 | 候选，未接线 |
| 右 DRV8871 IN2 | PB9 | TIM4_CH4 / AF2 | 候选，未接线 |

四路同属 TIM4，便于统一 PWM 频率和上电双低。它们同时复用 I2C/CAN/SDIO 等功能，后续启用这些外设前必须重新做冲突检查。当前 H2 固件没有配置 TIM4 或这些引脚，因此不得按此表直接给 DRV8871 接线。

在编码器电平和板卡引脚最终确认前，不创建会驱动电机的固件代码。
