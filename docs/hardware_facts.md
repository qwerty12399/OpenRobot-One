# OpenRobot-One 当前硬件事实

本文件只记录照片、官方资料、板卡资料或实测能够支持的事实。商品页内容必须标记为“卖家标称”，没有测量的数据保持 `UNKNOWN`。

## STM32 与通信

- 开发板：`LXBF407ZG-P1 V2.0`，MCU 为 `STM32F407ZGT6`。
- HSE：8 MHz；系统时钟基线：168 MHz。
- SWD：`PA13/PA14`；状态 LED：`PC13`，低电平点亮。
- 已验证 USART1：`PA9=TX`、`PA10=RX`、115200 8N1。
- CH340 继续交叉连接 `TXD -> PA10`、`RXD <- PA9`、GND共地。
- 当前 H2 固件没有 PWM、编码器、PID 或电机命令看门狗。

## 电机

- 用户确认已按双电机方案采购两台 JGA25-370。
- 现有照片/商品资料标称 `DC 12V / 620RPM`，带 AB 霍尔编码器。
- 卖家资料出现约 9.6:1、11 PPR、3.3/5 V编码器、约1.3 A堵转等信息；全部必须通过实物和测量复核。
- 电机线色不能替代插头针位或测量。

## IBT-2/BTS7960

三张卖家截图保存在 `硬件参数图片/bts7960/`。可辨认的接口为：

- 控制：`RPWM`、`LPWM`、`R_EN`、`L_EN`、`R_IS`、`L_IS`、`VCC`、`GND`；
- 动力：`B+`、`B-`、`M+`、`M-`；
- 卖家标称 VCC=5 V、输入3.3–5 V、PWM最高25 kHz、动力约6–27 V、最大43 A。

限制：

- 商品图同时写5.5–27 V与6–27 V，存在冲突；
- 商品图对 RPWM/LPWM 正反转定义互相冲突；
- 43 A不是已验证连续能力，也不能保护约1 A级小电机；
- 截图文字同时出现74HC244和“74HC224”，芯片型号标注本身也不一致；即使实物为74HC244，它也只是逻辑缓冲，不是电气隔离；
- 若芯片以5 V供电，STM32 3.3 V高电平是否满足实际模块阈值仍为 `UNKNOWN`；
- `R_IS/L_IS` 比例、范围和STM32接口保持 `UNKNOWN`，首次不接。

## 候选引脚

板卡原理图、背面丝印和 ST 复用表支持以下无冲突候选：

| 功能 | 引脚 |
| --- | --- |
| 左 RPWM / LPWM | `PB6/TIM4_CH1`、`PB7/TIM4_CH2` |
| 右 RPWM / LPWM | `PB8/TIM4_CH3`、`PB9/TIM4_CH4` |
| 左 R_EN / L_EN | `PC0`、`PC1` |
| 右 R_EN / L_EN | `PC2`、`PC3` |
| 左编码器 | `PA0/TIM2_CH1`、`PA1/TIM2_CH2` |
| 右编码器 | `PA6/TIM3_CH1`、`PA7/TIM3_CH2` |

候选引脚当前未被 `OpenRobotFirmware.ioc` 占用，并在核心板排针引出。它们仍需 CubeMX、通断和无动力电平验收后才能冻结。

用户对话中的 `PA8/PA9/PA10/PA11` 四 PWM 方案不采用：`PA9/PA10` 已属于 USART1，`PA11` 接板载 USB D-。EN 不得固定接5 V，四个 EN 各外接约10 kΩ下拉并由 PC0-PC3控制。

## 仍为 UNKNOWN

- 两块到货模块的芯片顶标、输入阈值、连续能力和热性能；
- 两台电机和编码器的逐台参数与一致性；
- 12 V/5 A适配器真实限流/保护特性；
- 最终保险丝、急停、限流和接线温升；
- 闭环误差、延迟、转速范围和架空估算里程计结果。
