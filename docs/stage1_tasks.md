# 双电机架空闭环任务清单

每个任务只在上一安全门通过后开始。未实测项保持 `UNKNOWN`。

## T1 实物盘点与证据整理

- 核对两块IBT-2、两台电机、12V/5A电源、一进二出端子和线材。
- 保存正反面、端子、标签和接线照片。
- 记录数量、型号、卖家声明和冲突。

验收：`docs/hardware_facts.md` 与实物照片一致。

## T2 H0安全装备

- 补齐万用表、保险丝、直流急停/开关和限流方案。
- 固定双电机、双驱动，隔离旋转轴和裸露动力端。

验收：缺任一项即 `BLOCKED`。

## T3 H1断电核查

- 测量B+/B-/M+/M-、公共地、短路和极性。
- 测量模块3.3V输入兼容性与编码器A/B电平。
- 安装PC0-PC3四个约10kΩ EN下拉。

验收：两套通道逐项记录，不以一套结果外推另一套。

## T4 H2引脚与安全状态

- TIM4 PB6-PB9四路PWM；PC0-PC3四路EN；TIM2和TIM3双编码器。
- 先GPIO低，再PWM=0，再完成自检，最后才允许EN。
- Fault、超时、串口错误和复位统一调用安全停车。

验收：无动力状态下抓取启动和故障波形/电平。

## T5 正式协议与看门狗

- 实现左右目标RPM、STOP、状态、故障、CRC和序号。
- 传输心跳不得刷新运动命令新鲜度。
- 覆盖截断、粘包、噪声、重复、回绕和超时。

验收：PC和STM32逐字节测试向量一致。

## T6 H3逐通道脉冲

- 先左后右，每次一个通道，首次5%/100ms。
- 每个台阶重新授权；异常立即断电。
- 冻结左右方向和编码器符号。

验收：到期、复位、断串口和PC退出均不产生持续输出。

## T7 编码器与开环

- 每轴手转一圈3次，离散度≤1%。
- 分别测量PWM、RPM、电流、温升和符号。
- 冻结安全开环范围。

## T8 H4双PID

- 单通道PID通过后再同时启用。
- 低/中/高三个目标点，每点10s、重复3次。
- 最后5s稳态误差≤10%，峰峰值≤15%。
- 10次命令超时均在550ms内关闭PWM和EN。

## T9 H5 ROS 2闭环

- `/cmd_vel`转换左右目标并发送STM32。
- 发布 `/bench/left_rpm`、`/bench/right_rpm`、编码器、状态、故障与 `/bench/odom_estimate`。
- 不发布真机 `odom -> base_footprint`。
- 保存1000个样本的延迟和错误统计。

## T10 交付

- 保存原始日志、测试命令、固件哈希和现场视频。
- 简历只引用实际通过的H门与真实指标。
