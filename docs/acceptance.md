# 功能验收标准

## 1. 工程与仿真

- ROS 2工作区构建和测试无错误。
- Gazebo存在 `/cmd_vel`、`/odom`、`/joint_states`、`/scan` 与目标TF。
- SLAM发布 `/map` 和唯一 `map -> odom`。

## 2. STM32 H2基线

- 固件构建、下载、verify和复位通过。
- USART1 PA9/PA10、115200 8N1双向通信通过。
- 压力、错误输入、半包、错误波特率和重连测试通过。
- 本节不证明电机安全或闭环。

## 3. H0/H1安全门

- 双电机架空固定，双驱动绝缘固定。
- 两块模块逐块验证端子、短路、极性、公共地和3.3V输入兼容性。
- 两个编码器逐个验证供电和A/B电平。
- MCU断电/复位时均为低。


## 4. H2电机安全固件

- PC6/PC7/PB0/PB1启动比较值为0；PC0-PC3启动为低。
- 上电、复位、HardFault、协议错误、串口错误均进入安全停车。
- 500ms运动看门狗独立于传输心跳和UART半包清理。

## 5. H3逐通道运动

- 左右分别完成一次授权的5%/100ms脉冲并准时停车。
- 方向与编码器符号由实测冻结。
- 复位、拔串口和PC进程退出不产生持续运动。

## 6. H4双电机闭环

- 两编码器各手转一圈3次，计数离散度≤1%。
- 左右单通道开环和PID先分别通过。
- 双通道低/中/高三目标点各运行10s、重复3次。
- 最后5s稳态误差≤10%，峰峰值≤目标绝对值15%。
- 10次超时测试中PWM和EN关闭延迟均≤550ms。
- 电流、温升、供电压降和异常均有原始记录。

## 7. H5 ROS 2架空闭环

- 四组 `/cmd_vel` 参考向量的离线、ROS和STM32目标一致。
- 左右目标/实测RPM、计数、状态和故障可观测。
- `/bench/odom_estimate`可复现且明确为架空估算。
- 真机台架只发布 `/bench/odom_estimate` 数据，不广播底盘 TF。
- ROS退出、串口断开和命令超时触发双通道停车。
- 1000个样本的延迟与错误统计真实保存。

## 8. 交付证据

每个H门保存日期、Git提交、配置、命令、原始输出。未生成的截图、视频和指标不得写入README或项目成果。
